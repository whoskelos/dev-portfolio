# Kelvin Guerrero — Portfolio

Sitio web personal y portfolio freelance. Construido con [Astro](https://astro.build) y Tailwind CSS.

## Desarrollo

```sh
pnpm install
pnpm dev
```

El sitio corre en `http://localhost:4321`.

## Comandos

| Comando        | Descripción              |
| -------------- | ------------------------ |
| `pnpm dev`     | Servidor de desarrollo   |
| `pnpm build`   | Build de producción      |
| `pnpm preview` | Vista previa del build   |

## Contenido

El texto y los datos del sitio están en `src/data/content.json`.
